# Smart File Organizer

A Python program that automatically organizes files into folders based on their file types.

## Features

- Organizes files by extension
- Supports images, videos, music, documents, applications, archives, and spreadsheets
- Handles unknown file types
- Handles files without extensions
- Skips existing folders
- Prevents duplicate filenames from being overwritten
- Shows a preview before moving files
- Asks for confirmation before making changes
- Displays a summary after organizing
- Handles file-moving errors safely

## Technologies Used

- Python
- pathlib
- shutil

## How to Run

Open the project folder in a terminal and run:
